# Демо-данные для ручной проверки

Папка содержит материалы демонстрационного курса в форматах, загружаемых
через экраны приложения. Команда `python -m app.cli seed-demo` загружает
те же данные автоматически (FR-65…FR-67).

## Состав

| Файл | Куда загружать |
|---|---|
| `Описание курса.txt` | Форма создания курса: первая строка — название, остальное — описание |
| `Описание задания 1.txt` … `Описание задания 4.txt` | Описание задания — загрузка из файла на форме задания (`.txt`) |
| `ДЗ1_DCF.xlsx`, `ДЗ2_Multiples.xlsx`, `ДЗ3_Capitalization.xlsx` | Материалы заданий (до 5 файлов на задание) |
| `Список студентов-Демо_группа 1.xlsx`, `Список студентов-Демо_группа 2.xlsx` | Экран импорта списка участников (`.xlsx`) |

## Что уже создано командой `setup` / `seed-demo`

- курс «Оценка бизнеса и инвестиции (демо)»;
- две группы: «Демо-группа 1» и «Демо-группа 2» — по пять студентов;
- куратор `curator@demo-study.ru` / `Demo1234`, прикреплённый к обеим
  группам;
- четыре задания: первое с дедлайном в прошлом (автостатус
  «Сдано после дедлайна»), материалы у первых трёх, у четвёртого без
  материала;
- сдачи всех пяти статусов, включая две вторые попытки.

Пароль всех демо-студентов: `Demo1234`. Вход администратора по
умолчанию: `admin@admin.com` / `1234` (обязательная смена логина и
пароля при первом входе, FR-02).

## Порядок ручной проверки

1. `python -m app.cli setup` — ключ, база и демо-данные; затем
   `flask --app app run`.
2. Войти администратором, сменить логин и пароль, открыть демо-курс:
   группы, участники, задания, дашборд, журнал.
3. Войти студентом (`vetrov@demo-study.ru` / `Demo1234`) и куратором —
   проверить свои экраны.
4. Для проверки импорта создайте **новый** курс и загрузите в него
   ростеры: импорт их же в демо-курс даст ошибки BR-06 (e-mail уже
   зарегистрирован в курсе). Названия групп в ростерах совпадают с
   демо-группами — в новом курсе они создадутся сами.
5. Создайте в новом курсе задание вручную: название и описание — из
   `Описание задания N.txt`, материал — `ДЗ*.xlsx`; в описании курса
   используйте строки файла `Описание курса.txt`.
